## 3. Interview cheat sheet — say each in your own words

1. **Web app vs mobile app** — a web app runs in a browser (JD Hub); a mobile app is installed on a phone (BizDocs).
2. **Database** — organised storage for information; lets you save and find data quickly. You use SQLite and PostgreSQL.
3. **API** — a way for two programs to talk. Example: your marketplace asks Flutterwave "did this payment succeed?"
4. **Frontend vs backend** — frontend is what the user sees; backend is the logic and data behind it.
5. **Python / Django / Flask** — Python is the language; Django and Flask are frameworks that speed up web apps.
6. **Git / GitHub** — Git tracks changes; GitHub stores code online so you can share and deploy.
7. **Deployment / hosting** — putting your app online for others to use (you use Render).
8. **Offline-first** — keeps working without internet, syncs later (BizDocs, School System).
9. **A bug** — a mistake in the code; you find it by testing and fix it.
10. **AI agent** — a program that uses an AI model to carry out tasks on its own; you're learning to build and use them.
11. **Mobile money integration** — connecting to MTN MoMo / Airtel so customers pay directly (MyMarket.ug).

**If you don't know something:** "I haven't worked with that yet, but here's how I'd approach it…" Never bluff.
